# Materiales de Sistemas Informáticos — 1.º DAW

Material docente elaborado por **José Fernández González** para el módulo profesional **Sistemas Informáticos** de **1.º del ciclo formativo de grado superior Desarrollo de Aplicaciones Web (DAW)**.

## Finalidad de esta carpeta

Esta carpeta reúne materiales de estudio, resúmenes, guías, ejemplos, prácticas y otros recursos docentes elaborados para facilitar el aprendizaje progresivo de los contenidos del módulo **Sistemas Informáticos**.

Los materiales están pensados principalmente para alumnado de Formación Profesional, aunque también pueden resultar útiles a docentes y a otras personas interesadas en los contenidos técnicos del módulo.

## Organización

Los materiales se organizan por unidades didácticas y, cuando proceda, por tipo de recurso.

Por ejemplo:

- `UD_01/`
- `UD_02/`
- `UD_03/`
- ...

La estructura podrá ampliarse conforme se publiquen nuevos materiales.
