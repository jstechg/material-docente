# Materiales docentes de Formación Profesional y recursos de programación

Repositorio personal de **José Fernández González** destinado a reunir y publicar materiales docentes, resúmenes, guías, ejemplos, prácticas y otros recursos técnicos relacionados con **Formación Profesional**, informática y programación.

## Finalidad del repositorio

Este repositorio tiene una doble finalidad:

1. Facilitar al alumnado y a otros docentes el acceso a materiales organizados y actualizados.
2. Servir como portfolio profesional público de los materiales elaborados por el autor.

Aunque inicialmente el contenido se centra en módulos de Formación Profesional, el repositorio podrá incorporar en el futuro materiales de programación, desarrollo de software y otras materias técnicas no ligadas necesariamente a un ciclo formativo concreto.

## Organización inicial

- [`1DAW_Sistemas_Informaticos/`](1DAW_Sistemas_Informaticos/) — Sistemas Informáticos, 1.º DAW.
- [`2DAW_Desarrollo_Web_Cliente/`](2DAW_Desarrollo_Web_Cliente/) — Desarrollo Web en Entorno Cliente, 2.º DAW.
- [`1SMR_Montaje_Mantenimiento_Equipos/`](1SMR_Montaje_Mantenimiento_Equipos/) — Montaje y Mantenimiento de Equipos, 1.º SMR.

La estructura podrá ampliarse con nuevas carpetas correspondientes a otros módulos, materias o contenidos de programación.

Cada carpeta principal puede contener su propio `README.md` y su propio archivo `LICENSE.md` o `COPYRIGHT.md`, según el régimen aplicable.
